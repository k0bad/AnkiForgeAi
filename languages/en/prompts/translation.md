Переведи английское слово на русский.
Дай 1-2 короткие варианта перевода на русский, через " / ".
Также дай короткую английскую фразу для поиска картинки на стоке (2-4 слова,
без артикля) — она нужна только для поиска картинок, а не для показа
пользователю. Фраза должна однозначно передавать то же значение слова, что и
твой русский перевод: уточняй его контекстными словами вместо голого
многозначного слова, а для абстрактных понятий описывай конкретную зримую
сцену или предмет вместо абстракции. EN — всегда ОДНА фраза с ОДНИМ значением:
если слово омоним и в RU: несколько вариантов через " / ", в EN: выбери
только то значение, которое передаёт первый RU-вариант — никогда не пиши
" / " в EN-строке. Примеры: "spring" (сезон) →
"spring season nature"; "spring" (пружина) → "metal coil spring"; "bank"
(финансы) → "bank building finance"; "bank" (берег) → "river bank shore";
"freedom" → "person arms open freedom".
Ответь РОВНО двумя строками в этом формате, без пояснений и кавычек:
RU: <перевод на русский>
EN: <английская фраза для поиска картинки, 2-4 слова>

# Разложить норвежские слова по темам

Тебе дан список тем и список слов. Для каждого слова выбери **одну** тему.

## Темы

Используй **только** темы из этого списка, скопированные точь-в-точь, вместе с
`::` и всеми дефисами. Тема из двух уровней (`dyr::fugler`) пишется целиком.

```
{topics}
```

## Как выбирать

- Тема — про **значение** слова, а не про его часть речи. `å bade` («купаться»)
  идёт в тему действий, а не в тему про воду.
- Двухуровневая тема лучше одноуровневой, если подходит: `mat-og-drikke::frukt`
  точнее, чем просто тема про еду.
- Слово с несколькими значениями клади по тому, которое стоит в переводе первым.
  `søt` с переводом «сладкий; милый» — про вкус и вид, а не про еду как предмет.
- Если ни одна тема не подходит по-настоящему — верни `null`. Пустая тема лучше
  натянутой: карточку с `null` человек разложит сам, а карточку в чужой теме он
  не заметит и не исправит.

## Слова

```json
{words_json}
```

## Ответ

Верни **только** JSON-массив, по элементу на каждое входное слово, в том же
порядке. `id` — эхо из входа, `topic` — строка из списка тем или `null`.

```json
[
  {{"id": 1062, "topic": "egenskaper"}},
  {{"id": 1089, "topic": null}}
]
```

Никакого текста до или после массива.
